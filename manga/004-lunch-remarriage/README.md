# 再婚しないと、幸せじゃない？

[ランチ版・40秒動画をダウンロード](https://raw.githubusercontent.com/noboru12164649-beep/SNS-/main/manga/004-lunch-remarriage/marriage_manga_reel_2026-10-30_lunch_40s_v1.mp4)

奈緒（36歳・離婚経験あり）、恵子（42歳・既婚）、真理（39歳・既婚）の友人ランチ。再婚を考えていない奈緒が、周囲に幸せを決めつけられて戸惑い、真理の問いかけを通じて自分の気持ちを取り戻す全11カットです。

作品名は固定表示せず、上部は各場面の出来事・心情を伝える地の文に変更しています。セリフと別の役割を持つタイトルだけを順に読んでも、物語を追える構成です。

奈緒は左（ラベンダー）、恵子は右（ピンク・真珠）、真理は中央奥（緑）。全編同じカフェの同じテーブルで着席。上下の金色装飾、太い明朝体、黒とえんじ色のタイトル、左右余白なし、最終CTAを維持。

1080×1920、9:16、30fps、H.264、音声なし、40秒・1200フレーム。30秒版は制作していません。
