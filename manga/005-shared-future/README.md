# 結婚のために、私だけが我慢するの？

[40秒動画をダウンロード](https://raw.githubusercontent.com/noboru12164649-beep/SNS-/main/manga/005-shared-future/marriage_manga_reel_2026-11-01_shared_future_40s_v1.mp4)

美穂（33歳）は交際半年の健太（36歳）から、結婚後の退職と家事の専任を一方的に求められる。同じ店にいた友人・沙織（35歳）の問いかけをきっかけに、お互いの希望を話し合える関係を望むと伝える婚活漫画です。

ユーザー提供の完成台本・セリフで制作。全11カット、1カット1コマ、場面ごとの地の文タイトル、上下の細い金色装飾、大きな明朝体、黒とえんじ色の文字、左右余白なし。

1080×1920、9:16、30fps、H.264、音声なし、40秒・1200フレーム。30秒版は制作していません。

## 人物と場面の連続性

美穂は栗色のハーフアップ、ローズ色カーディガン。健太は黒髪、紺ジャケット、薄いグレーのシャツ。沙織は黒髪ボブ、青緑のジャケット。同じレストラン、二人は同じテーブルに着席したまま。

沙織は1〜5カットで左奥の別席に登場。6カット目に立って美穂の左へ来て声をかけ、以降も立ったまま。7〜10カットの沙織と健太の会話では、発言者・相手・視線を区別。11カット目は美穂が健太を見て意思表示し、沙織が見守ります。
