# 参考画像に合わせた見出しデザインの改善（v13）

## 参考画像から採用した点

今回の比較対象は、ユーザー提供の4枚の画面画像です。画像から確認できる構成・書体・配色・余白の差分を改善しました。

| 要素 | 変更前 | v13 |
| --- | --- | --- |
| 装飾 | 左右の大きな花・蔦が見出しの横幅を占める | 見出しの外周と四隅だけの細い金色の枠に整理 |
| 書体 | ゴシック体 | 太い日本語明朝体（Noto Serif CJK JP Bold） |
| 文字量 | 一文が長く、文字を小さくして配置 | 地の文のまま短く整理し、2行・1行7〜11文字程度に統一 |
| 文字サイズ | 動画上で約53〜60px | 1行目約87px、2行目約91〜103px。文字をつぶさず自然な比率で表示 |
| 配色 | 行全体を赤・黒で分ける | 基本は黒、出来事・感情の変化を示す語句だけをえんじ色に強調 |
| レイアウト | 装飾が目立ち、文字が中央に小さく見える | 文字を主役にして横幅を活用。見出しの余白は文字の読みやすさに配分 |

## 維持した内容と確認

- 本文の人物、背景、吹き出し、セリフを描き直さず、タイトル欄だけを更新。
- 最終CTA「今の婚活に不安がある人は／プロフィールをチェック」を維持。
- 左右に漫画の余白・縦枠を追加せず、下部の金色の装飾と1カット1コマを維持。
- 各元画像のタイトル欄より下が、変更前と画素単位で一致することを確認。
- 360×640の表示で、冒頭・長めの見出し・最終ページの視認性を確認。
- 40秒版と30秒版を1080×1920・30fps・音声なしで出力。フレーム数・尺・全編デコードを確認。

## 次回の制作AIに渡すデザイン指示

上部は短い地の文を2行で表示する。1行7〜11文字程度を基準に、タイトルだけで物語が追える順序にする。セリフにある内容語やその言い換えを繰り返さない。最終ページは場面から導けるメッセージにする。

書体は太い明朝体。黒を基本とし、2行目の重要な出来事や感情を示す語句だけをえんじ色で強調する。1080px幅の動画で見出し本文をおよそ90〜100pxにし、長い場合は先に文章を短くする。文字を縦横に変形させない。句読点と色分けした語句は同じベースラインにそろえる。

上部の背景は淡いアイボリー〜薄いピンク。金色の装飾は四隅と細い外周線に限定し、大きな花や蔦で文字の領域を狭めない。漫画は左右の余白・縦枠なし。人物、背景、セリフを変えない修正では、タイトルだけを差し替える。

最後にタイトルとセリフを横に並べて重複を照合し、スマートフォン相当の360px幅で文字の欠け・圧縮・読みにくさを確認する。
