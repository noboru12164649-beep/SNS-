## 画像からリールを作る場合

1. 画像を01〜06の順に並べます。
2. 各画像を5秒に設定します（合計30秒）。
3. 画面比率9:16、1080p、30fpsで書き出します。

公開前に、Instagramのプロフィールのリンクからオプチャに入れることをご確認ください。
