# 「いい人なのに好きになれない」婚活漫画

親しみやすい絵柄の漫画を、縦型ショート動画に合わせた9:16で制作しました。36歳の娘を、婚活の決めつけからお母さんが守る物語です。

- 画像6枚と動画はすべて1080×1920（9:16）
- 上部に金色の飾り罫と赤・黒のタイトル
- セリフは吹き出し、コマ割りと漫画の効果線を使用
- 画像右上の配番は削除済み

## 画像からリールを作る場合

1. 画像ファイルを01〜06の順に並べます。
2. 表示時間を順に5・4・4・6・5・6秒に設定します（合計30秒）。
3. 画面比率9:16、1080p、30fpsで書き出します。
