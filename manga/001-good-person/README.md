# 「いい人なのに好きになれない」婚活漫画

親しみやすい丸い絵柄・吹き出し・コマ割りで描いた漫画です。36歳の娘を、婚活の決めつけからお母さんが守る物語です。

## 動画

[30秒のリール動画（MP4）を開く](manga-reel-30s.mp4)

- 縦型9:16・1080×1920・30fps
- 吹き出し付きの漫画6枚を順番に表示
- 文字数に合わせて、表示時間を5・4・4・6・5・6秒に調整（合計30秒）
- 音声・BGMなし
- GitHubのファイル画面の「Download raw file」からダウンロードできます。

## 画像からリールを作る場合

1. 画像を01〜06の順に並べます。
2. 表示時間を順に5・4・4・6・5・6秒に設定します（合計30秒）。
3. 画面比率9:16、1080p、30fpsで書き出します。
