# 将来の話をしただけで、重い女？

[40秒動画をダウンロード](https://raw.githubusercontent.com/noboru12164649-beep/SNS-/main/manga/006-future-talk/marriage_manga_reel_2026-11-04_future_talk_40s_v1.mp4)

交際3年の拓也（38歳）に将来の相談を拒まれた香織（35歳）が、電話で友人・理沙（36歳）に相談し、悲しかったのは結婚の結論ではなく対話を拒まれたことだと気づき、拓也に待ち続けない意思を伝える全11カットの漫画リールです。

ユーザー提供の完成台本・セリフに沿って制作しました。全編、場面ごとに変わる地の文タイトル、上下の金色装飾、太い明朝体、黒とえんじ色の文字、左右余白なし、1カット1コマ。

1080×1920、9:16、30fps、H.264、音声なし、40秒・1200フレーム。30秒版は制作していません。

## 場面の連続性

1〜5：拓也の自宅。チャコールソファ、青いクッション、テレビ、木製ローテーブル。香織は左、拓也は右。

6：帰宅した香織が理沙に電話。クリームソファ、セージグリーンのカーテン、ランプのある自宅。背後に拓也の部屋での出来事を淡い回想として重ねています。

7〜8：電話の相手・理沙の自宅。白い本棚、ベージュの椅子、小さなテーブルランプ。

9：香織の自宅へ戻り、理沙との通話中に自分の気持ちに気づく。

10：相談を終えて拓也へかけ直す。男性の音声は、電話アイコンと「拓也（電話）」ラベル付きの吹き出しで区別。

11：香織が同じ自宅から意思を伝え、電話先で言葉を失う拓也の姿を淡く重ねています。回想・電話先のイメージはぼかした重ね描きとし、別枠のコマ割りは設けていません。
